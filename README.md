# Illuminite New Tab

A beautiful makeover for your new tab. Works in Firefox 109+ and Chromium browsers.

## Load it (unpacked)

**Firefox:** open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on**, and pick `manifest.json`.
Temporary add-ons are removed when Firefox closes; to keep it, package and sign it through addons.mozilla.org, or use Firefox Developer/Nightly with `xpinstall.signatures.required` set to false.

**Chrome / Edge / Brave:** open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and pick this folder.

## Use it

- Type in the search bar and press Enter to search in a new tab (or open a typed link).
- Click **Add app** to save a website. Right-click an app to rename it, edit its link, or remove it.
- Press and hold an app for one second, then drag it to a new spot.
- The three-line button (bottom right) holds add app, screensaver, theme, sound, settings, and save/load file.
- Your apps and settings are kept in extension storage and stay until you uninstall the extension. **Save to file** makes a backup you can load again with **Load from file** (the screensaver video is not included in the file).
- Hold down on an app until it becomes slightly smaller to move it.

**Desktop Mode**
Desktop basics

    Double-click an icon to open it in a window (or turn on single-click in Desktop & taskbar).
    Drag windows by the title bar, resize from the bottom-right corner, double-click the title bar to maximize.
    Click the Start button, or just type after opening it, to find apps. Recently used apps show under Recommended.

Icons

    Drag any icon to move it. Icons snap to a grid (change this in Settings) and never overlap.
    Press and drag on empty desktop to draw a selection box and pick several icons. Hold Ctrl or Shift to add to the selection.
    Drag a selected icon to move the whole group. Right-click the selection to open, align or remove them together.
    Right-click the desktop and choose New shortcut to add a website right where you clicked.
    Select an icon and press F2 to rename it, or Delete to remove a shortcut.

Apps

    Notepad saves automatically. Calculator, Clock, Paint, Task Manager and a simple Browser are built in.
    Websites open in a window. If a site shows a blank page, it doesn't allow being embedded: use Open in new window.

Leaving

    Use Start, then the power button, then Exit desktop mode. The sliver at the far right of the taskbar shows the desktop.
