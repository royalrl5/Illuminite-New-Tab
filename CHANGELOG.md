# Changelog

## 1.4.1

- Removed voice search

## 1.6.0

- Desktop mode restyled to look like Windows 11: centered taskbar, new Start menu with pinned and recommended apps, flat window controls
- Move desktop icons freely (snap to grid optional); drag a box to select several and move, open or remove them together
- Right-click the desktop: New shortcut (placed where you clicked), align icons, personalize
- Settings app with Personalization, Desktop & taskbar, Mouse & cursor, Sound, System, Data & backup, How to use and About
- Cursor: choose custom colors or upload a .cur, .ani or image file
- YouTube and GitHub no longer added by default

## 1.5.0

- Page title is back to "New Tab"
- Right-click an app: Open in new tab / Open in new window (a real browser window)
- Desktop mode (monitor button in the bottom-left corner): startup animation and sound, custom cursor, windows, taskbar, Start menu
- Built-in desktop apps: Notepad, Calculator, Clock, Paint, Task Manager, Browser
- Tab is renamed "New Tab (Desktop Mode)" while in desktop mode; the new tab always starts in the normal page

## 1.4.0

- Renamed to Illuminite New Tab
- Screensaver only closes with Esc (moving the mouse or clicking no longer exits)
- New "Features and how to use" guide in the menu

## 1.3.0

- Voice search: mic button on the search bar (needs a browser with the Web Speech API, such as Chrome)

## 1.2.4

- Added Firefox data_collection_permissions (none); requires Firefox 140+

## 1.2.3

- New logo: abstract glowing color orbs, used as the tab icon and the extension icon

## 1.2.2

- Removed the Activities button from the top bar

## 1.2.1

- Search engine picker on the search bar (DuckDuckGo default; also Google, Bing, Brave, Startpage, Ecosia, Yahoo)

## 1.2.0

- Light and dark themes (or match the system)
- Press and hold an app for one second to pick it up, then drag to reorder
- Three-line menu button in the bottom right
- Glass app tiles with fading translucent borders
- Everything is saved in extension storage and stays until you uninstall
- Save to file / Load from file for backups

## 1.1.0

- Web apps: add by link, rename without touching the link, edit link, remove
- Wallpapers: six built-in plus upload your own image
- Screensaver: animated aurora or your own uploaded video; optional idle start
- Synthesised sound effects
- Firefox support (Manifest V3)

## 1.0.0

First public beta.
